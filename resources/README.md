# Additional Resources

This folder contains additional resources that participants can use to continue learning after the workshop.

## Python

* Python documentation: https://docs.python.org/3/
* Python Beginner's Guide: https://wiki.python.org/moin/BeginnersGuide

## Git and GitHub

* Git documentation: https://git-scm.com/doc
* GitHub Skills: https://skills.github.com/

## Further Learning

Participants are encouraged to continue practising Python after the workshop by building small projects, working through coding exercises, exploring open-source projects, and participating in Python community activities.

PyLadies Kampala will also continue to share learning opportunities and community activities that participants can join after the workshop.
