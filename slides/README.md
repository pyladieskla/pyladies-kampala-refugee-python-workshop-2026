# Workshop Slides

This folder contains the presentation materials used during the PyLadies Kampala Refugee Python Workshop 2026.

The sessions introduce participants to Python programming through practical examples and guided exercises.

## Topics Covered

The workshop presentations cover:

1. Introduction to Python
2. Variables and Data Types
3. Strings and User Input
4. Lists and Dictionaries
5. Conditional Statements
6. Loops
7. Functions
8. Working with Files
9. Building a Small Python Project
10. Introduction to Git and GitHub
11. Introduction to Open Source

Presentation slides will be added to this folder as they are prepared for the workshop.
