# PyLadies Kampala Refugee Python Workshop 2026

## Python Practical Learning Materials

Welcome to the learning materials for the **PyLadies Kampala Refugee Python Workshop 2026**.

This workshop is designed for refugees and persons of concern who are interested in learning technology and building practical programming skills. The sessions are beginner-friendly and focus on learning by doing.

Participants will work through practical Python exercises during the workshop, with support from facilitators and mentors.

## Workshop Topics

The curriculum covers the following areas:

1. Introduction to Python
2. Variables and Data Types
3. Strings and User Input
4. Lists and Dictionaries
5. Conditional Statements
6. Loops
7. Functions
8. Working with Files
9. Practical Python Project
10. Introduction to Git, GitHub and Open Source

## Learning Approach

The workshop combines short explanations with hands-on exercises. Participants will write and run Python code themselves and work through practical problems with guidance from facilitators and mentors.

No previous Python or open-source experience is required.

## Learning Outcomes

By the end of the workshop, participants should be able to:

* Write and run basic Python programs.
* Understand common Python data types.
* Use variables, conditions, loops, and functions.
* Work with lists, dictionaries, and basic files.
* Solve simple programming problems using Python.
* Build a small practical Python project.
* Understand the basics of Git and GitHub.
* Understand what open source is and how they can continue learning and contributing.

## Who This Is For

The workshop is designed for beginners who are interested in technology and want to start or continue their programming journey.

Participants do not need previous Python experience.
